## What is exchangerateapi.net?

exchangerateapi.net provides fast, reliable, and developer‑friendly currency data. This organization collects language‑specific SDKs and examples so you can integrate quickly across Node, Python, Go, Ruby, PHP, Swift, Dart/Flutter, and Meteor.

- Two core endpoints: latest rates and historical rates by date
- Generous free tier for development and light workloads
- Simple authentication via API key
